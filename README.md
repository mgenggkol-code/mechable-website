# MECHABLE Website

This is a static, mobile-responsive company website.

## Free hosting
Recommended: GitHub Pages.

1. Create a GitHub account at github.com.
2. Create a new public repository named `mechable-website`.
3. Upload `index.html`.
4. In Settings → Pages, select Deploy from branch → main → /(root).
5. GitHub will provide a free `github.io` address.
6. In the Pages custom domain setting, enter `mechable.in`.
7. At Hostinger DNS, point the domain to GitHub Pages using the DNS records GitHub shows for your repository. GitHub's current documentation should be followed for the exact records.
8. Enable HTTPS after DNS has propagated.

The site contains no paid scripts or external libraries.
